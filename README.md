# AMap — Проверка маппинга и названий объектов

Скрипт для администрации **Родина РП** (MoonLoader 0.26+)

## Установка

1. Скачать `amap.lua` и положить в папку `moonloader/`
2. Зайти в игру — скрипт загрузится автоматически

## Команды

- `/amap` — открыть главное меню

## Возможности

- Проверка домов, бизнесов и трейлеров по ID
- Автоматическое получение ника владельца (дома/бизнесы)
- Отправка уведомлений о нарушении названия или маппинга
- Автообновление при выходе новой версии

## Автообновление

Скрипт автоматически проверяет наличие новой версии при каждом запуске и обновляется без участия пользователя.

## Версия

Текущая версия: **1.0**
